# פורטל המנהלת — אבטיפוס אינטראקטיבי

אבטיפוס Frontend עבור **מנהלת החטופים, הנעדרים והשבים**.

- React + TypeScript + Vite
- Tailwind CSS v4 + רכיבי UI בסגנון shadcn
- Lucide icons
- עברית מלאה · RTL
- **נתוני דמה בלבד** — אין חיבור ל־Salesforce / DB

ריפו ייעודי לאבטיפוס הפורטל בלבד (יוצא מ־`Life` / `portal/` אחרי מיזוג PR #13). אין כאן את אפליקציית Flutter Life.

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחו את הכתובת שמוצגת בטרמינל (ברירת מחדל: `http://localhost:5173`).

בנייה:

```bash
npm run build
npm run preview
```

## החלטת ניווט: צדדי (sidebar)

נבחר **תפריט צד קבוע** (מימין ב־RTL) לתפקידים התפעוליים (מת״ם / מולקולה), עם **סרגל עליון** לחיפוש, התראות, פעולה חדשה ופרופיל.

**נימוק:** סביבת עבודה ארגונית עם יעדים קבועים (משימות, יחידות, ידע, בית המנהלת) מרוויחה מניווט אנכי מתמשך; הסרגל העליון נשאר פנוי לפעולות אופקיות גלובליות. במובייל התפריט הופך למגירה. פורטל המשפחות משתמש במעטפת נפרדת ומינימלית (ללא ניווט תפעולי).

## Design system

מסמך העיצוב: [`DESIGN.md`](./DESIGN.md) — **Stitch mockups** הם מקור האמת לוויזואל במעבר זה.

יישום הטוקנים בפועל: `src/index.css` (`@theme`).

- Ink Navy `#1a2b4b` (כפתורים ראשיים), Signal Blue `#1976d2`, Cloud `#f5f7fa`
- כרטיסים לבנים, צל רך, רדיוס ~12px; סטטוס־פילים אדום/צהוב/ירוק
- **Heebo** + **Assistant** (עברית)

## הנחות מסומנות ב־UI

סימוני «הנחה לא מאומתת» מופיעים במסכים הרלוונטיים, בין היתר:

1. הפרדת Chatter (משותף/פנימי) — לאימות מול Salesforce  
2. שדות חובה בפתיחת משימה — הנחה שמרנית  
3. ביקורים/שיקום — אבטיפוס מבני, ללא מידע קליני  
4. תוכן בית המנהלת — דמה בלבד  
5. הרשאות מולקולה — ללא שינוי סטטוס/סגירה  

רשימה מרוכזת גם ב־`src/data/mock.ts` → `ASSUMPTIONS`.
